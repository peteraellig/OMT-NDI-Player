Version 1.1.0.3 adds combined OMT/NDI playback, automatic input meters for up to eight channels, selectable stereo/mono monitoring, receive quality settings and the optional HTTP API (default port 25901).

Includes API password/show controls, an English API Help window and OMT receive-bandwidth display. NDI bandwidth remains n/a.

Download and run OMTplay-1.1.0.3-Setup-x64.exe on Windows x64. The .NET runtime and playback dependencies are included.
